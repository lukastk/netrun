# Testing Folder

This folder contains example netrun configuration files for testing the UI.

## Files

- `example.netrun.json` - A multi-node example with various port types
- `simple.netrun.toml` - A minimal two-node flow in TOML format

## Usage

When you run `./start.sh` from the `netrun-ui` directory, the file explorer will automatically open to this folder.

You can create your own test files here - they will be ignored by git (see `.gitignore`).
